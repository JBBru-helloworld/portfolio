# jbbru.com

Personal portfolio of Joshua Bonham. Next.js (App Router) deployed to Cloudflare Workers with OpenNext.

```bash
pnpm install
pnpm dev        # Next.js dev server
pnpm preview    # OpenNext build, run in the local Workers runtime
pnpm deploy     # OpenNext build and deploy to Cloudflare
```

The previous site is kept in `legacy/` for reference until launch.
