# assets/

The owner's original media goes here: full-resolution photos, video plates and source files.

- Originals are never committed and never bundled. Everything in this folder except this README is gitignored.
- Only optimised derivatives made for the app are shipped, from `public/` or the source tree.
- The window-scene files (the keyed window image and the two cloud videos) go in `assets/window-scene/`.
